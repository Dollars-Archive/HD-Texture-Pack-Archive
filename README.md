# Dollars Archive HD texture pack

게임별 HD 텍스처 팩을 모읍니다.

[HD texture pack 모음](https://dollars-archive.github.io/HD-Texture-Pack-Archive/) · [한글패치 모음](https://dollars-archive.github.io/Dollars-Archive/)

가디언 엔젤의 HD 팩 보유가 확인되어 목록에 등록했습니다.
배포 파일은 아직 등록되지 않았습니다.

팩 등록 원본은 `packs.json`입니다. 게임명·기종·에뮬레이터와 확인된 다운로드 주소를 기록합니다.
파일을 올리기 전에는 `download_url`을 비워 두며, 사이트는 배포 파일 준비 중으로 표시합니다.
패치 저장소와 연결된 게임 표지는 한글패치 모음에서 재사용합니다.

파일 등록·수정 시 자동으로 목록을 생성하고 사이트에 배포합니다.
